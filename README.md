# Data Storage and Processing Systems - Homework 2

## О проекте

Проект по работе с реляционной базой данных PostgreSQL, включающий полный цикл обработки данных: от анализа качества до построения аналитических запросов на очищенных данных.

## Критические проблемы исходных данных

Исходные данные содержали **грубые ошибки**, сделавшие работу с ними слишком сложной для учебного задания:

### Основные проблемы:
- **Дубликаты product_id** - один ID `0` использовался для 19 совершенно разных продуктов
- **Нарушение ссылочной целостности** - заказы ссылались на несуществующих клиентов и продукты
- **"Мусорные" данные** - пустые строки, некорректные форматы

### Конкретные примеры косяков:
- `product_id = 0` использовался для 19 различных продуктов с разными брендами, категориями и ценами
- 1,378 заказов ссылались на несуществующие продукты (`product_id = 0`)
- 3 заказа от клиента `5034`, которого не было в базе

## Ключевые решения и исправления

### 1. Борьба с дубликатами продуктов
- Обнаружил, что один product_id = 0 соответствует 19 разным продуктам
SELECT COUNT(*) FROM product WHERE product_id = 0; -- 19 записей!
- Создали чистую таблицу с уникальными продуктами
  
### Сохранение финансовой целостности. 
Проблема: При очистке продуктов я случайно создал 57,326 записей в order_items вместо 20,000
Причина: Один старый product_id стал ссылаться на несколько новых продуктов
### Решение:
Полностью пересоздал order_items из исходного CSV
Добавили "Unknown Product" для product_id = 0
Сохранил все 1,378 исторических заказов на сумму 3.1 млн долларов

### Настройка связей и индексов.
Добавил первичные ключи на все таблицы
Настроил внешние ключи для ссылочной целостности
